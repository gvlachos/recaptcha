reCAPTCHA (Sept 2026) — Frontend Reference Implementation

This form demonstrates the reference integration pattern: a score-based reCAPTCHA token is generated on submit and sent to a backend endpoint for verification (see the companion recaptcha-backend reference project's src/routes/verify.js). The frontend never decides pass/fail itself — that decision always happens on the backend, where it cannot be bypassed by disabling or editing this page's JavaScript.
